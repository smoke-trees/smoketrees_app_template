# Agent Guidelines — Stac App (generated from smoketrees_app_template)

This Flutter app was generated by the **smoketrees_app** Mason brick. It already contains Stac (Server-Driven UI) infra. Use this file as the single reference for how to work inside this app.

## Stack

- Flutter + Dart (`sdk: ^3.12.0`, `flutter_lints` via `analysis_options.yaml`)
- Stac DSL (`stac/lib/` → `stac build` → JSON in `stac/.build/` + `stac/.dev-build/`, rendered by `lib/stac_runtime/`)
- GetX for app controllers/bindings/navigation, Dio + Hive for network/storage when `include_network_layer=true`
- Codegen: `json_serializable` + `hive_generator` via `build_runner`

## Layout (what you have after `mason make`)

- `lib/app/` — routes (`app_pages.dart`, `app_nav.dart`), `init_bindings.dart`
- `lib/core/` — `controllers/`, `network/dio_controllers/`, `services/`, `storage/hive.dart`
- `lib/shared/` — reusable non-Stac widgets (only place for generic UI)
- `lib/stac_runtime/` — your custom Stac widgets/actions + `stac_registry.dart` + `utils/`
- `lib/theme/` + `lib/utils/` + `lib/enums/` — theming, helpers, typed enums
- `stac/lib/` — `@StacScreen` sources (e.g. `hello_world.dart`) → compiled by Stac CLI
- `assets/` — images/svgs/lotties (declared in `pubspec.yaml`)
- `example/` — present only if you chose `include_example_screens=true`
- `create_stac_parser.dart` / `create_stac_action.dart` — scaffolders; `default_stac_options.dart` — Stac config

## Flutter & Dart Conventions (project enforces `flutter_lints`)

- **Format:** `dart format .` before every commit. No manual formatting overrides.
- **Analyze:** `flutter analyze` must be zero issues. `analysis_options.yaml` includes `package:flutter_lints/flutter.yaml`.
- **Files:** `snake_case.dart`, one widget/screen per file. Colocate Stac triples: `st_foo.dart` + `st_foo.g.dart` + `st_foo_parser.dart`.
- **Types:** `PascalCase` types, `camelCase` members/params, `SCREAMING_SNAKE` constants. Prefer typed models over `dynamic`; avoid `any`.
- **Widgets:** `const` constructors + `super.key`, small composable widgets. Shared UI → `lib/shared/`; server-driven behavior → `lib/stac_runtime/`.
- **State:** follow existing GetX (`GetxController`, `Rx`, `Obx`, `Bindings`, `Get.find()`). Do not introduce Bloc/Riverpod.
- **Imports:** Dart → Flutter → package → relative, sorted, no unused.
- **Logging:** no `print`; use `lib/utils/console_logger.dart` / `pretty_dio_logger`.

## Stac Rules

- Custom widget/action = model (`@JsonSerializable`) + `StacParser<T>` + registration in `lib/stac_runtime/stac_registry.dart` (and `example/...` if examples enabled).
- Screens live in `stac/lib/` with `@StacScreen(screenName: '...')`; `screenName` == `Stac(routeName: ...)`.
- Scaffold: `dart run create_stac_parser.dart <Name> [category] [subdir...] [--inject-data]` and `dart run create_stac_action.dart <Name> [category]`.
- Never rename JSON fields / parser `type` strings after shipping — server payloads break.
- Navigation only via `lib/app/app_pages.dart` / `StWildcardPageNav` — no ad-hoc routes.

## Prerequisites & First Run

- Flutter/Dart, Mason CLI (`dart pub global activate mason_cli`), Stac CLI (`dart pub global activate --source git --git-path packages/stac_cli --git-ref main https://github.com/smoke-trees/st_sdui.git`), Tailscale for `stac watch`.
- `mason make` already ran `flutter pub get` + `build_runner` + `stac build`. If Stac CLI was missing, run `stac build` manually. iOS: set `platform :ios, '15.0'` in `ios/Podfile` then `pod install` (see `README.md`).

## Daily Workflow

1. `flutter pub get` after `pubspec.yaml` changes
2. `dart run build_runner build --delete-conflicting-outputs` after model/hive changes
3. `stac build` after touching `stac/lib/`
4. Dev loop: `stac watch` (Funnel) + `flutter run` in second terminal (or `stac watch --no-app` separate)
5. Before PR: `dart format --output=none --set-exit-if-changed .` + `flutter analyze` + `flutter test` + relevant codegen/build checks

## Verification

- `dart format --output=none --set-exit-if-changed .`
- `flutter analyze`
- `flutter test`
- `dart run build_runner build --delete-conflicting-outputs` when models/g.dart change
- `stac build` when Stac DSL changes

## Safety

- Don't hand-edit `stac/.build/`, `stac/.dev-build/`, `.dart_tool/`, `build/`, `*.g.dart`.
- Update `README.md` when setup or structure changes.
- Don't commit secrets/`.env`, `build/`, `.dart_tool/`, `.stac/` (see `.gitignore`).
- Skills: `.agents/skills/grill-me`, `grill-with-docs`, `grilling` + `.claude/skills/` mirrors are intentional; use them to grill plans before implementing.
